# Notes — why each doc earns its place

Optional background reading. **Nothing in this folder gets copied into your project** —
the thing you copy is [`../docs-template/`](../docs-template/). Start with the
[folder README](../README.md) for setup.

Each note is a few paragraphs on the reasoning behind one `docs/` file — the failure it
prevents, the war story that shaped it, and the one part people get wrong. They're
numbered to match the video walkthrough.
