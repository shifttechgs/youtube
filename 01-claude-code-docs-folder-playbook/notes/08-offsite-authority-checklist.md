# Companion note · off-site authority

> Explains **[`docs-template/citations.md`](../docs-template/citations.md)** — directory
> citations, referral partnerships, digital PR. Copy it (with the rest of
> `docs-template/`) into your project as `docs/citations.md`.

This note is background, not a file you copy.

## Why this is a separate doc

Once the on-page work is done, external validation moves a local business's ranking more
than any further schema you add. But **the agent can't do any of it** — every signup
needs email or phone verification, sometimes a document upload, that the owner controls.

So this doc isn't a task list for the agent. It's **prep**, so each action is a
five-minute copy-paste for the owner instead of a from-scratch write.

## The one thing that has to be exact: NAP

Name, address, phone — **identical** across every listing. A phone formatted three
different ways across three directories actively hurts local ranking. The doc carries one
canonical block; you paste it verbatim, never reformat per-platform.

## What's prepped in the file

- The canonical NAP block + primary/secondary categories + service area.
- Short (~150 char) and long (~700 char) descriptions, ready to paste.
- A directory table (claim the auto-created listing, don't make a duplicate; feed the
  live URL back into `sameAs` schema — *that's* what turns a listing into a signal).
- A partnership outreach email and a local-press pitch, both with the blanks marked.

## Keep the status tables current

Each channel has a status + date. Update them as things go live, and hand the profile
URLs to whoever maintains the site so they land in the `LocalBusiness` `sameAs` array.
