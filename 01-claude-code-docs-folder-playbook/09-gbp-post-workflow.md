# Google Business Profile posts

A queue of ready-to-publish GBP "Update" posts, plus a log of what's already gone out.
Posted **manually** in the GBP dashboard (no API integration): copy the text, set the
CTA + link, attach a real photo, publish.

**Cadence:** weekly. Every post is tied to something real — a blog post, a genuine
operational change, a seasonal angle, a real before/after photo. **Never a fabricated
claim or stock-photo filler.**

## How to publish one

1. Copy the post text into GBP → Posts → Update.
2. Set the CTA button and link exactly as noted.
3. Attach a **real** job/crew photo from the gallery — not stock. Photo posts get
   meaningfully more views than text-only.
4. Move the entry from **Queue** to **Posted** with the date, so nothing gets reused
   too soon.
