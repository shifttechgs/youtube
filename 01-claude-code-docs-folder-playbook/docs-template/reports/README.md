# Reports — frozen snapshots

Dated, point-in-time documents: audits, strategy write-ups, competitive analyses. Unlike
the files one level up, **these are never edited after the day they're written.** They're
the historical record; the living docs (`../seo.md`, `../memory.md`) carry current state.

## Convention

- **Filename:** `YYYY-MM-DD-short-slug.md` — e.g. `2026-07-14-seo-geo-audit.md`.
- **First line inside:** the date and what triggered the report, so it stands alone if
  someone opens it in a year.
- **Don't update a report.** If something changed, that goes in the living doc, or a new
  dated report — not an edit to the old one.
- Link the relevant report from the `memory.md` timeline entry that references it.

*(This folder is intentionally kept in version control while empty.)*
